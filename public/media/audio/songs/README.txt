ANSHIKA ARCHIVE - CUSTOM LOVE SONGS DIRECTORY
=============================================

You can place your high-quality MP3 / OGG audio files in this directory:

Recommended filenames:
- perfect.mp3 (or perfect.ogg) -> "Perfect" by Ed Sheeran
- rut.mp3 (or rut.ogg)         -> "Rut" by Navjot Ahuja
- ambient_hub.mp3              -> Custom Hub ambience
- ambient_gallery.mp3          -> Custom Gallery ambience

NOTE:
If no audio file is placed here, the archive automatically plays
a bespoke, procedurally synthesized high-fidelity acoustic guitar & piano
harmonic arrangement of these exact songs via Web Audio API!
No plugins, subscriptions, or external network connections required.
